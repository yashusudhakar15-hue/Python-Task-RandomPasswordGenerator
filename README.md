
# Random Password Generator

## About the Project
This is a Python-based Random Password Generator developed as part of the Oasis Infobyte Python Programming Internship.

The program generates random passwords based on the length entered by the user.

## Features
- Generates random passwords.
- Allows users to choose password length.
- Includes uppercase and lowercase letters.
- Includes numbers and special characters.
- Handles invalid inputs.
- Checks that the password length is at least 4.

## Technologies Used
- Python
- VS Code

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
py password_generator.py
```

4. Enter the required password length.
